# GHW Copilot Simple App

A simple personal portfolio website that introduces **Rishabh Jain**, his skills, projects, experience, achievements, and contact information.

The site is designed to work on both computers and phones, with interactive project sections that make it easy to explore his work. It was created for **GitHub Global Hack Week**.

## Live Website

[Visit the portfolio](https://ghw-copilot-simple-app-rishabhs-projects-b1721277.vercel.app)

## What can you find here?

- **About:** Learn more about the person behind the projects.
- **Skills and experience:** Explore technical skills and experience.
- **Projects:** Browse projects and filter them by area, such as software, IoT, and robotics.
- **Achievements:** See highlights and accomplishments.
- **Contact:** Find ways to get in touch.

## Want to run it?

You can try the website on your own computer without installing extra packages.

1. Download this repository or clone it:

   ```bash
   git clone https://github.com/RISHABH12005/GHW-C2.git
   cd GHW-C2
   ```

2. Open the `index.html` file in your web browser.

That’s it—the website is made with HTML, CSS, and JavaScript, so it does not need a build step.

## Project files

- `index.html` — the content and sections of the website.
- `styles.css` — the appearance and layout, including mobile styles.
- `script.js` — interactive features such as navigation and project filters.

## Want to make changes?

You can edit the text and sections in `index.html`, change the appearance in `styles.css`, or adjust the interactive features in `script.js`.

## Built with

HTML, CSS, and JavaScript. The website is hosted on [Vercel](https://vercel.com/).
