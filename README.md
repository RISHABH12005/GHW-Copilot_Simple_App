# GHW Copilot Simple App

A responsive, single-page portfolio website for Rishabh Jain, built with **HTML5, CSS3, and vanilla JavaScript**. It presents personal information, technical skills, projects, experience, achievements, and contact details in a clean, mobile-friendly interface.

## Live Demo

**[View the live website on Vercel](https://ghw-copilot-simple-app-rishabhs-projects-b1721277.vercel.app)**

## Features

- Responsive layout with mobile navigation
- About, skills, projects, experience, achievements, and contact sections
- Project filtering by IoT, software, and robotics
- Interactive project-details dialog
- Contact form feedback and an email link
- Lightweight static website with no build step or external dependencies

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling, layout, and responsive design
- **JavaScript** — navigation, project filters, dialogs, and interactions
- **Git and GitHub** — version control and source code hosting
- **Vercel** — website deployment and hosting

## Run Locally

### Option 1: Open directly

Clone the repository and open `index.html` in your browser:

```powershell
git clone https://github.com/RISHABH12005/GHW-Copilot_Simple_App.git
cd GHW-Copilot_Simple_App
start .\index.html
```

### Option 2: Start a local HTTP server

If Python is installed, run:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser. Keep the terminal open while using the site, and press `Ctrl+C` to stop the server.

## Project Structure

- `index.html` — page structure and content
- `styles.css` — layout, responsive styles, and visual design
- `script.js` — navigation, filters, dialogs, and interactions

## Customization

- Update text and page sections in `index.html`.
- Adjust colors, layout, and responsive behavior in `styles.css`.
- Modify navigation and interactive features in `script.js`.

## Deployment

The website is deployed on Vercel. Changes committed to the repository can be deployed through the Vercel project when Git integration and automatic deployments are configured.
