# GHW Copilot Simple App

A responsive, single-page portfolio website for Rishabh Jain, built with plain HTML, CSS, and JavaScript. It highlights his background, technical skills, projects, experience, achievements, and contact information.

## Features

- Responsive navigation with a mobile menu
- About, skills, projects, experience, and achievements sections
- Project filters for IoT, software, and robotics
- Interactive project details dialog
- Contact form feedback and email link
- Lightweight static site with no build step or dependencies

## Run locally

You can open `index.html` directly in a browser, or serve the site locally:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project files

- `index.html` — page content and structure
- `styles.css` — layout, responsive styles, and visual design
- `script.js` — navigation, filters, dialogs, and interactions

## Customization

Edit the content in `index.html`, visual styles in `styles.css`, and interactive behavior in `script.js`.
